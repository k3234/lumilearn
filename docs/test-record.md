## 四、Bug 与迭代改进记录

### 4.1 评测脚本 prompt 回显 bug（已修复）

- **现象**：`generate()` 返回完整序列含 prompt，导致答案判定错误。
- **修复**：切片 `out[0].tolist()[len(ids):]` 仅保留模型生成部分。

### 4.2 幻觉误报 bug（已修复）

- **现象**：`1/2` 中的 `/` 被误判为"单位"分隔符，7B 模型幻觉率虚高到 66.67%。
- **修复**：新增 `_is_real_unit()` 过滤纯符号与变量上标（x²/y³ 非单位）。
