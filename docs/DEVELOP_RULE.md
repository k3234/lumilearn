# LumiLearn-Beta 完整开发规则（AI-Agent 执行约束，竞赛版本）

> 目标：全国青少年人工智能创新挑战赛 AI 智能体专项赛
> 版本：Beta 参赛版
> 基准：基于 MAIC 范式，应用层改良，非从零训练基座

---

## 1 顶层业务约束（不可改动）

**项目定位**：借鉴 OpenMAIC 的 MAIC 多智能体课堂范式，面向国内高中数理化学科自学场景，做三处工程改良：

- **改良①**：Ollama 本地 / 云端 API 双适配，低配 CPU 设备可运行演示
- **改良②**：K-12 高中数理化业务适配
- **改良③**：学情数据回流，自进化知识库闭环，动态调整授课难度

**禁止宣称**：创造全新范式、性能全面超越 OpenMAIC；文档统一表述为"基于已有范式完成场景化工程改进"。

**禁止**：硬编码 API-Key，所有凭证放入环境变量 `.env`，`.env` 加入 `.gitignore`。

**Beta 版本不强制实现**：TTS 语音、幻灯片导出、3D 可视化；以上归入 `future-roadmap` 后续规划。

**远期规划固定写入全部文档**：调度内核后续抽离重构为通用 Agent 运行时 LumiFlow。

## 2 架构分层强制约束

四层分层，代码必须逻辑隔离，禁止模块耦合混乱。

### 模型适配层（adapter）

- 统一抽象调用接口；屏蔽 DeepSeek、Qwen、Ollama 的调用差异。
- 开关配置：切换云端模式 / Ollama 本地模式。
- 必须捕获异常：429 限流、超时、网络断开；对模型幻觉输出增加教学风险提示标记。

### Agent 调度层（agent_runtime）

固定三个角色，角色职责不可混淆：

- **TeacherAgent**：知识点讲授、出题、解析
- **PeerAgent（AI 同学）**：课堂提问、课堂讨论互动
- **DirectorAgent**：课堂流程调度、状态流转、控制对话终止、切换测验环节

提示词全部外置配置文件，不硬编码在业务代码。

### 业务课堂层（classroom）

PDF 文档解析，知识点拆分；课堂会话管理；测验生成；答题结果解析。

### 持久存储层（storage）

- 保存会话记录、测验结果、错题标记、学情标签；
- 学习数据输出，回流到学情知识库，用于调整后续授课深度；
- 文件本地持久化，重启保留状态。

## 5 Git 提交规范

用于评审 / 面试查看迭代轨迹，禁止一次性大批量提交全部文件。

提交前缀固定：

- `feat:` 新增业务功能
- `fix:` bug 修复
- `docs:` 更新文档、报告、说明
- `refactor:` 代码重构、模块解耦
- `perf:` 性能优化

示例：

```
feat: 实现Ollama模型适配器，支持本地模式切换
docs: add comparison-maic.md OpenMAIC对比文档
```

## 6 学术文本固定话术（报告、README 统一）

### 国内外现状段落模板

> 本项目借鉴 OpenMAIC 所提出 MAIC 多智能体交互式课堂范式，并未提出全新范式。针对原版系统存在部署门槛高、缺少面向国内 K-12 学情长期记忆机制、缺少低配硬件适配等问题，完成三项工程层面改进：①实现 Ollama-云端双模式适配；②面向国内高中数理化学科做业务流程适配；③构建学情知识库闭环，学习记录自动回流用于动态调整授课难度。本项目为应用层改良原型，尚未完成大规模对照实验，仅基于小范围案例开展验证，系统存在大模型幻觉、本地基座能力受限等客观局限。

### 未来工作固定表述

> 后续迭代计划将 Agent 调度内核抽离，重构为通用 Agent 运行时框架 LumiFlow，对外提供 Skill 插件兼容能力，把 LumiLearn 作为上层教育应用 Demo。
