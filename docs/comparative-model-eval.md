## 五、评测方法与局限

1. **答对判定**：
   - 带单位答案（如 2m/s²）：生成文本包含该「数值+单位」对；
   - 纯数值答案（如 5、1/2、8π）：包含等价文本（含小数/π 近似）或全部核心数字；
   - 文本答案（如 单调递增）：包含答案核心文本或近义词（递增/严格递增）。
2. **幻觉判定**：
   - 单路（关）：仅「数值+单位」同单位不同值矛盾检测；
   - 双路（开）：单路规则 + FactCheckerAgent 与 RAG 知识库核对；
   - 说明：无单位答案不判定数值幻觉，避免 3²+4² 计算中间数字误报。
3. **采样**：Qwen-7B 使用 temperature=0 确定性采样，结果可复现；
   8M 本地模型使用固定 seed 采样。
4. **局限**：
   - 评测集为自建固定样例（每科 10 题），非标准权威题库，样本量有限；
   - 答对判定偏宽松（等价文本匹配），不能完全等价人类批改；
   - 幻觉检测以数值冲突为主，语义级幻觉依赖 FactChecker 规则，存在漏检可能；
   - 8M 模型为教学内容生成模型（非答题模型），直接答题并非其设计用途，
     本报告旨在客观披露能力边界。
