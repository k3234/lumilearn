# LumiLearn 3 分钟讲解视频脚本

> **用途**：APAI 亚太人工智能青少年科技创新大赛
> **时长**：3 分钟（180 秒）
> **格式**：MP4，建议 1080p，25fps
> **配音**：中文普通话，语速适中（约 180 字/分钟）

## 脚本正文

**画面**：项目 Logo + SDG 4 图标 + 世界地图标注教育不平等区域

>
> 全球有数亿学生无法接触到 AI 教育工具，原因很简单——它们需要昂贵的 GPU。而 LumiLearn 的目标是：让每一台 4GB 内存的普通电脑，都能成为 AI 教学终端。

---

### 【0:25 - 0:55】技术架构介绍（30 秒）

**画面**：系统架构图动画 + 核心代码片段

**旁白**：
> LumiLearn 采用五层架构：前端展示层、API 网关层、业务逻辑层、多 Agent 协作层、模型推理层。
>
> 核心创新点有三个：
> 第一，自研 8M 参数 Transformer，全部在 CPU 上训练；
> 第二，纯 Python BM25 检索引擎，零外部依赖；
> 第三，多 Agent 协作系统，基于费曼五步教学法。

### 【0:55 - 1:40】演示案例（45 秒）

**画面**：浏览器录屏，展示数学·勾股定理学习流程

**旁白**：
> 现在让我演示一个完整的数学学习案例。
>
> 输入主题"勾股定理"，系统自动进入费曼五步教学：
> 第一步，从生活场景引入——帮家里装修计算对角线长度；
> 第二步，制造认知冲突——为什么不是简单相加？
> 第三步，构建思维模型——a² + b² = c²；
> 第四步，引导学生自主推导；
> 第五步，费曼测试检验理解。
>
> 同时，Self-Critique Agent 实时评分，CoachAgent 推荐个性化学习路径。整个过程约 56 秒，全部在本地 CPU 完成。

## 录制建议

### 设备要求
- 屏幕录制：OBS Studio 或系统自带录屏
- 分辨率：1920×1080
- 帧率：25fps 或 30fps
- 音频：USB 麦克风或手机录音后同步

### 录制步骤
1. **准备阶段**：启动 LumiLearn 服务，确保所有端口正常
2. **架构部分**：使用 PPT 或项目架构图截图
3. **演示部分**：使用真实浏览器操作，提前准备好登录状态
4. **数据部分**：使用预先准备好的性能图表
5. **配音**：单独录制旁白，与画面同步

### 注意事项
- 演示操作要流畅，避免卡顿
- 代码片段要清晰可读
- 数据图表要简洁明了
- 旁白语速控制在 180 字/分钟左右

---

## 备用方案

如果浏览器演示不稳定，可准备以下备用：
1. **截图序列**：提前截取关键界面，用 PPT 播放
2. **预录 API 调用**：使用 curl 命令录制终端操作
3. **动画演示**：用动画演示学习流程，减少真实操作依赖
