## 案例一：数学 — 勾股定理

### 基本信息
- **学科**：数学
- **知识点**：勾股定理（直角三角形三边关系）
- **难度**：高中
- **预计耗时**：5-7 分钟

### 演示步骤

#### Step 1：启动学习
```
主题：勾股定理
学科：数学
难度：高中
```

#### Step 2：现象引入（Feynman 第 1 步）
AI 从生活场景引入：
> "你正在帮家里装修，需要知道客厅地面的对角线长度。已知客厅是矩形，长 3 米，宽 4 米，请问对角线多长？"

#### Step 3：认知冲突（Feynman 第 2 步）
AI 制造认知冲突：
> "你可能觉得对角线就是 3+4=7 米，但实际测量会发现不是这样。为什么？"

#### Step 4：思维模型（Feynman 第 3 步）
AI 构建数学模型：
> "勾股定理：直角三角形中，斜边的平方等于两直角边的平方和。即 a² + b² = c²"

#### Step 5：自主推导（Feynman 第 4 步）
AI 引导学生推导：
> "请用这个公式计算：长 3 米、宽 4 米的矩形，对角线多长？"

#### Step 6：费曼测试（Feynman 第 5 步）
AI 给出自测题：
> "一个直角三角形，直角边分别为 5cm 和 12cm，求斜边长度。"

### 预期输出
- 学生正确回答：斜边 = 13cm（因为 5² + 12² = 25 + 144 = 169 = 13²）
- 系统评分：100 分
- 掌握度：优秀
- 推荐：进阶练习（勾股定理实际应用）

### RAG 来源
```
[1] 勾股定理 - 百度百科
[2] 直角三角形边角关系 - 教科书
```

## 案例二：物理 — 牛顿第二定律

### 基本信息
- **学科**：物理
- **知识点**：牛顿第二定律（F = ma）
- **难度**：高中
- **预计耗时**：5-7 分钟

### 演示步骤

#### Step 1：启动学习
```
主题：牛顿第二定律
学科：物理
难度：高中
```

#### Step 2：现象引入
AI 从生活场景引入：
> "为什么推空购物车比推装满货物的购物车容易？这与力和加速度有什么关系？"

#### Step 3：认知冲突
AI 制造认知冲突：
> "有人说力越大速度越大，但为什么力越大加速度越大，而不是速度越大？"

#### Step 4：思维模型
AI 构建数学模型：
> "牛顿第二定律：F = ma（力 = 质量 × 加速度）
> 加速度与力成正比，与质量成反比"

#### Step 5：自主推导
AI 引导学生推导：
> "一个 10kg 的物体受到 50N 的力，加速度是多少？"

#### Step 6：费曼测试
AI 给出自测题：
> "一个 2kg 的物体以 3 m/s² 的加速度运动，受到的力是多少？"

### 预期输出
- 学生正确回答：F = 2 × 3 = 6N
- 系统评分：100 分
- 多 Agent 协作结果：
  - FeynmanTeacher：ok（5 步完成）
  - SelfCritique：ok（评分 100）
  - CoachAgent：ok（推荐：摩擦力与牛顿定律）

### RAG 来源
```
[1] 牛顿第二定律 - 物理教科书
[2] 力与加速度的关系 - 实验演示
```

## 案例三：化学 — 共价键

### 基本信息
- **学科**：化学
- **知识点**：共价键（共享电子对）
- **难度**：高中
- **预计耗时**：5-7 分钟

### 演示步骤

#### Step 1：启动学习
```
主题：共价键
学科：化学
难度：高中
```

#### Step 2：现象引入
AI 从生活场景引入：
> "水分子（H₂O）为什么稳定存在？氢原子和氧原子是如何结合的？"

#### Step 3：认知冲突
AI 制造认知冲突：
> "钠原子失去电子变成 Na⁺，氯原子得到电子变成 Cl⁻，它们通过离子键结合。但水分子中没有离子，它们怎么结合？"

#### Step 4：思维模型
AI 构建概念模型：
> "共价键：两个原子通过共享电子对形成的化学键
> 例如：H-O-H，每个氢与氧共享一对电子"

#### Step 5：自主推导
AI 引导学生推导：
> "请画出水分子（H₂O）的电子式，说明每个原子如何达到稳定结构。"

#### Step 6：费曼测试
AI 给出自测题：
> "甲烷（CH₄）分子中，碳原子与几个氢原子形成共价键？"

### 预期输出
- 学生正确回答：碳原子与 4 个氢原子形成 4 个共价键
- 系统评分：100 分
- 掌握度：优秀
- 推荐：进阶（离子键 vs 共价键对比）

### RAG 来源
```
[1] 共价键定义 - 化学教科书
[2] 分子结构与化学键 - 在线资源
```

## 演示操作指南

### 方法一：浏览器演示（推荐）
1. 启动服务：`python -m framework.api.server --multi-port`
2. 访问学生端：http://localhost:5010
3. 登录学生账号（默认：student01 / password）
4. 选择学科和主题，开始学习
5. 录制屏幕操作过程

### 方法二：API 调用演示
```bash
# 登录
curl -X POST http://localhost:5010/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"student01","password":"password"}' -c cookies.txt

# 发起学习（数学·勾股定理）
curl -X POST http://localhost:5010/api/learn/start \
  -b cookies.txt \
  -d '{"topic":"勾股定理","subject":"数学","difficulty":"高中"}'
```

### 方法三：多 Agent 协作演示
```bash
# 多 Agent 全流程
curl -X POST http://localhost:5000/api/multi-agent \
  -H 'Content-Type: application/json' \
  -d '{
    "topic":"牛顿第二定律",
    "subject":"物理",
    "difficulty":"高中",
    "student_explanation":"F=ma"
  }'
```
