# LumiLearn 复赛→决赛迭代路线图

> **生成日期**：2026-08-21
> **适用赛道**：GOAI 无界应用（AI+教育）、全国青少年人工智能创新挑战赛
> **核心原则**：复赛补证据 + 强化已有闭环，少新增大功能；决赛再开发高阶能力；全程围绕「算力平权、K12 理科自适应学习、班级学情闭环」主线

---

## 一、复赛必做提升（文档 + 评测 + 工程，优先级最高）

> GOAI 复赛评审重点：可复现、量化证据、场景价值、安全合规、完整任务闭环。
> 最大拉分点：**实证材料**，不是新功能。

### 1. 评测与实证材料

| 任务 | 内容 | 产出 |
|---|---|---|
| ① 标准化测试集评测 | 固定数理题样例，对比 8M 自研模型 vs Qwen-7B 答题正确率；对比开启/关闭双路事实校验的幻觉错误率 | `docs/comparative-model-eval.md` |
| ② CPU 低配性能基准 | 普通笔记本环境下，Agent 链路平均耗时、失败率、内存占用；客观写明性能短板，不回避延迟 | ✅ 已有 `docs/performance-benchmark.md` |
| ③ 小规模真实用户证据 | 10-15 名中学生试用，问卷反馈摘要 + 使用记录截图 | ✅ 已有 `docs/USER_TEST_REPORT.md`（12 人内测）|
| ④ 差异化对标文档 | 明确与 OpenMAIC 的定位差异：OpenMAIC 做沉浸虚拟课堂，LumiLearn 做课后自学 + 学情管理 | `docs/COMPARISON_WITH_OPENMAIC.md`（新增）|
| ⑤ 安全伦理声明定稿 | AI 幻觉风险、数据隐私、AI 辅助开发边界三者完整披露 | ✅ 已有 `RISK-STATEMENT.md` + `AI-DECLARATION.md` |

### 2. 工程与部署可靠性

| 任务 | 内容 | 产出 |
|---|---|---|
| ⑥ Lite 模式优化 | 增加日志开关，关闭非必要仪表盘日志，降低 CPU 负载 | `framework/lite_mode.py` 升级 |
| ⑦ 业务 Bug 修复 | 错题存储、权限校验、学情统计异常全面排查 | pytest 新增用例 |
| ⑧ 部署脚本打磨 | Docker + 一键脚本保证全新机器完整复现；补充故障排查手册 | `docs/TROUBLESHOOTING.md`（新增）|
| ⑨ 固定 Demo 演示脚本 | 预设教材片段，规避现场演示随机性 | `scripts/demo_fix_scenario.sh`（新增）|

### 3. 现有模块打磨（不加新大功能）

| 任务 | 内容 |
|---|---|
| ⑩ RAG 流水线稳定性 | 优化文档分片，减少解析乱码 |
| ⑪ 三层记忆可视化 | Admin 面板可查看 Agent 记忆 / 错题记忆 / 会话记忆内部链路 |

## 二、复赛可选加分功能（选 2-3 个，不要全部）

| 功能 | 难度 | 收益 | 说明 |
|---|:---:|:---:|---|
| **内置数理计算器工具调用** | 中 | ⭐⭐⭐⭐⭐ | 解决理科计算幻觉；只做 MCP 最小版本；学生做题时自动调用，Demo 直观 |
| **学情薄弱点 AI 诊断** | 低 | ⭐⭐⭐⭐ | 基于错题记录输出知识点薄弱清单；教师后台直接查看 |
| **测试试卷自动生成** | 低 | ⭐⭐⭐⭐ | 按知识点生成单元测试卷；面向教师场景 |
| **导出学情报告 PDF** | 低 | ⭐⭐⭐ | 教师一键导出班级学情文档 |

> **禁止复赛开发**：白板、TTS 语音、虚拟数字人——炫技功能，分散核心定位。

## 三、决赛冲刺高阶功能（复赛全部完成后才开发）

### 技术内核层面

| 功能 | 说明 |
|---|---|
| Agent 调度层解耦重构 | 串行调度抽离独立模块，借鉴状态机思想，业务与调度分离 |
| RAG 双模式开关 | 默认 BM25（低配 CPU）；高配机器可开启向量检索 |

### 产品业务层面

| 功能 | 说明 |
|---|---|
| 教材批量导入 | 支持完整课本，自动拆分章节、知识点，构建学科知识库 |
| 作业批改流水线 | 教师上传作业文档，系统批量批改 + 班级错题统计 |
| 简易 MCP 工具扩展 | 除计算器外，增加公式解析工具，控制复杂度 |

### 开源生态

| 功能 | 说明 |
|---|---|
| 开发者文档完善 | 接口注释、类型注解、二次开发指南 |
| Roadmap 路线规划 | 展示长期维护可能性，非一次性 Demo |

## 四、答辩演示重点

1. **完整闭环链路**：导入教材 → 费曼教学 → 出题练习 → AI 批改 → 错题入库 → 学情仪表盘
2. **内部 Trace 日志**：现场展示 Agent 每一步思考、记忆调用链路
3. **模型对比演示**：8M 微型模型 vs Qwen-7B 同期对比，直观展示算力平权
4. **材料出示**：评测表格 + 用户试用报告纸质/PPT

---

## 五、风险红线（全程禁止）

| ❌ 禁止项 | 原因 |
|---|---|
| 大规模重构 Agent 内核 | 破坏已跑通的闭环，风险极高 |
| 堆砌多媒体功能（白板/TTS/数字人） | 冲淡「低配算力平权」核心定位 |
| 同时开发全部可选功能 | 战线过长，质量失控 |
| 口头夸大模型效果 | 文档如实写明能力边界 |

---

## 六、阶段总结

| 阶段 | 取胜关键 | 禁止事项 |
|---|---|---|
| **复赛** | 证据、可复现、闭环稳定 | 不堆新功能，先补材料 |
| **决赛** | 工程深度、架构优化思路、落地潜力 | 不在复赛前开发高阶功能 |
| **全程** | 守住「低配硬件 K12 理科自适应学习」定位 | 不和 OpenMAIC 硬卷虚拟课堂 |
