# LumiLearn v0.2.0-beta 配置包

> 版本：v0.2.0-beta　|　仓库：github.com/k3234/lumilearn（PUBLIC）　|　发布日期：2026-09-11
> 架构：**统一双端口** —— `18080` 管理门户（教师/学生/仪表盘/管理端）、`18081` REST API ＋ **lumi 单色极简设计系统**

本包用于在任何 Linux / macOS / Windows 主机上**独立、最简化**部署 LumiLearn v0.2.0-beta。

---

## 一、本包包含什么

```
config/framework.yaml        运行配置（version=0.2.0-beta，端口/端口映射/Ollama/安全/资料管线）
.env.example                全环境变量模板（占位符，无真实凭据）
Dockerfile                  镜像构建（python:3.10-slim）
requirements.txt            依赖清单
deploy/                     一键部署体系：
  install.sh / install.ps1 / install.mjs   网络管道式安装（curl|bash / irm|iex / npx）
  bootstrap.sh/.ps1/.bat                  从零一键部署入口
  setup.py/.sh/.bat                       配置引导（检测/依赖/端口/模型）
  start.py/.sh | stop.py                  跨平台启动/停止
framework/                  核心服务（api/server.py 含全新建库修复、routes/models/服务）
remote/templates/           前端模板（13 个，lumi 设计系统换肤）
static/ui/                  lumi 设计系统令牌（lumi.css / icons.css / icons/）
scripts/deploy_remote.py    远程部署助手（凭据经环境变量注入）
docs/                       版本、引导、测评、架构等文档
```

## 二、独立引导（推荐：单行管道安装）

**无需先下载任何脚本**，直接生成仓库主干的单行安装即可（自动完成 检测 git/python → 克隆/更新 → 配置 → 启动）：

```bash
# Linux / macOS
curl -fsSL https://raw.githubusercontent.com/k3234/lumilearn/master/deploy/install.sh | bash

# Windows PowerShell
irm https://raw.githubusercontent.com/k3234/lumilearn/master/deploy/install.ps1 | iex
```

**手动方式（仓库已克隆）：**
```bash
bash deploy/bootstrap.sh        # 一键：clone/更新 → 配置 → 启动
# 或分步
python deploy/setup.py          # 交互式配置（端口/模型/管理员初始密码）
python deploy/start.py          # 读取 framework.yaml + .env 启动全部启用服务
python deploy/stop.py           # 停止服务
```

> 默认管理员：`admin`。新部署时初始密码由 `LUMILEARN_ADMIN_INITIAL_PASSWORD` 指定（未指定则随机生成并打印到日志），**首次登录必须改密**。

## 三、最简化运行（仅保留核心学习服务）

若资源受限、只想跑通基础服务（无需 torch / manim 等重依赖）：

```bash
pip install flask requests pyyaml python-dotenv
SECRET_KEY=$(python -c "import secrets;print(secrets.token_hex(32))") \
LUMILEARN_ADMIN_INITIAL_PASSWORD='你的强密码' \
python -m framework.api.server --multi-port
# 访问 http://<host>:18080/
```

## 四、关键配置项（.env / config/framework.yaml）

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `SECRET_KEY` | 必填 | 主 API session 加密密钥（生产缺失拒绝启动） |
| `LUMILEARN_ADMIN_INITIAL_PASSWORD` | 随机 | 管理员初始密码，首次登录强制改密 |
| `LUMILEARN_ENV` | development | `production/prod` 时对缺失密钥 fail-closed |
| `OLLAMA_BASE_URL` | http://localhost:11434 | 模型服务地址（可经环境变量覆盖） |
| `framework.yaml` 端口映射 | 18080/18081 | 两端口架构，教师/学生/仪表盘/分析已并入门户 |

## 五、安全基线

- 双端口需各自鉴权：管理 API 走 `X-Admin-Token`，页面路由走 session；分析与日志类接口默认 401。
- 本包**不含任何真实内网 IP / 主机用户名 / 口令 / API Key**（全为占位符）。
- 依赖项若加入 CI，建议启用依赖锁文件与安全扫描。
