# LumiLearn 发展规划（GOAI 技术报告精简版）

LumiLearn 定位为准入教育场景的开源多 Agent 学习辅助平台，主打算力平权——普通 CPU 设备即可完整部署。系统以开源大模型（Qwen/DeepSeek）为基座，核心价值在于自研的 Agent 调度流水线、分层记忆系统、RAG 知识库与业务 Web 平台。

**短期（V2-V2.5，竞赛版本）**：重点加固多 Agent 异常降级与 trace 可视化、增强 RAG 检索质量与来源引用、构建自动化评测集与报表、完善工程健壮性与安全声明，形成完整闭环参赛版本。

**中期（V3，产品化）**：将 Agent 内核与记忆、Skill 能力抽离为独立 SDK（Lumi-Agent-Core），实现 MCP 兼容的插件系统，拓展学习计划编排、错题本导出、教师批量管理等教学场景，保留本地私有化与云端 API 两种部署形态。

**长期（V4，架构演进）**：维持混合基座策略，重心投入上层系统而非基座预训练；推进微服务拆分与多租户支持，适合学校小规模试点部署。

全程坚持产品边界：AI 辅助教育工具，不替代教师，所有输出需人工校验，不做公有云 SaaS 运营，MIT 开源协议。
