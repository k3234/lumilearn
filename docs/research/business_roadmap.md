## 二、本地-云混合训练架构设计

### 2.1 本地（R7-7840HS）职责

| 任务 | 描述 |
|------|------|
| ✅ 代码开发 | 模型架构、训练脚本、Agent 逻辑 |
| ✅ 小规模测试 | 小数据集快速验证、单元测试 |
| ✅ 数据集构建 | 教育指令数据收集与清洗 |
| ✅ 文档编写 | 技术文档、教程、博客 |
| ❌ 大规模训练 | 太耗时，算力不够 |
| ❌ 高并发服务 | 不适合生产环境 |

### 2.2 云端职责

| 任务 | 描述 |
|------|------|
| ✅ 模型预训练 | 用更大算力，花更短时间 |
| ✅ 模型微调 | 教育场景微调 |
| ✅ 推理服务 | 对外提供 API |
| ✅ 高并发访问 | 生产环境部署 |

### 2.3 分工示例

```
工作流
├── 周一到周五：本地
│   ├── 写代码/修 bug
│   ├── 测试新想法
│   ├── 构建数据集
│   └── 写文档
│
└── 周六/周日：云端
    ├── 推送代码到 GitHub
    ├── 启动云服务器
    ├── 运行训练/微调
    ├── 下载模型文件
    └── 本地验证
```

## 三、云服务器选型方案

### 3.1 主流云服务商对比

| 服务商 | 优势 | 劣势 | 推荐场景 |
|--------|------|------|----------|
| **阿里云** | 国内访问快、中文文档好 | 价格稍贵 | 国内用户 |
| **腾讯云** | 价格友好、学生优惠 | 文档稍逊 | 预算敏感 |
| **AWS** | 功能最强、实例最全 | 价格贵、操作复杂 | 海外/高要求 |
| **Colab Pro** | 极便宜、按需按小时 | 稳定性一般、限制多 | 短期实验 |
| **AutoDL** | 性价比高、GPU 全 | 网络不稳定 | 纯训练 |

### 3.2 不同配置的实例（2026参考价格）

| 配置 | 性能 | 日租（约） | 可训练规模 | 适合场景 |
|------|------|------------|------------|----------|
| **RTX 4090 (24GB)** | 中高 | ¥80-100 | 50-100 亿参数 | 微调 |
| **RTX 5090 (32GB)** | 高 | ¥150-200 | 100-200 亿参数 | 预训练+微调 |
| **A100 (80GB)** | 极高 | ¥600-1000 | 500 亿+ 参数 | 大规模 |

### 3.3 推荐的启动配置（2026.6-9）

```
初期方案（低成本）
├── 云服务商：阿里云/腾讯云/Colab Pro
├── 实例：RTX 4090 或 RTX 5090（看预算）
├── 时间：每周六/周日（按需付费）
├── 月成本：¥400-800
└── 目标：教育微调完成
```

```
中期方案（服务上线）
├── 云服务商：阿里云/腾讯云
├── 实例：RTX 5090 + 固定带宽
├── 时间：按需弹性伸缩
├── 月成本：¥1000-2000
└── 目标：API 服务上线
```
