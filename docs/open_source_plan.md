# LumiLearn 开源路线图（Open Source Plan）

> 日期：2026-08-12 · 初赛提交前
> 目标：从"参赛作品"走向"开放教育基础设施"，让每个学校都能在普通电脑上部署自己的 AI 教官。

---

## 一、为什么开源

| 理由 | 说明 |
|---|---|
| **教育公平** | 让缺乏算力的学校也能获得 AI 教学能力（本地优先架构专为此设计） |
| **社区共建** | 教学内容库、费曼教学模板、训练数据由师生共同贡献 |
| **技术透明** | AI 教育的黑箱不透明是公众担忧，开源让教学过程可审查 |
| **持续迭代** | 单靠开发者的力量有限，社区驱动才能长期演进 |

---

## 二、路线图

### Phase 1（8 月）— 核心功能开源

## 三、开源范围与边界

| 开源内容 | 说明 |
|---|---|
| ✅ 核心引擎 | feynman_engine、lumilearn_multi_agent、lumilearn_agent、adaptive_learning |
| ✅ 服务框架 | framework/api、database、teacher_portal、admin |
| ✅ 模型工具 | 训练脚本、数据构建、GGUF 转换 |
| ✅ 教学数据规范 | 数据 schema、构建流程（真实数据由社区提供） |
| ⚠️ 敏感配置 | 不包含任何服务器 IP、密码、API Key（仅 `.env.example` 占位） |

## 四、社区建设计划

1. **内容贡献**：教师提交真实教学问答 → 审核通过后进入 `training_data` 表，持续提升 RAG 检索质量。
2. **模型共建**：本地微调脚本开放，学校可用自己的教学数据训练"本校专属模型"。
3. **插件生态**：Skill 机制（`skills/` 目录）允许任何人封装自己的教学法为 Skill。

---

## 五、合规与伦理

- 开源代码遵循 Apache-2.0 许可证，标明第三方依赖。
- 教学数据仅接受授权内容，版权归贡献者或采用知识共享许可。
- 开源版本默认关闭云端推理，保护学生隐私（详见 `privacy_compliance.md`）。
