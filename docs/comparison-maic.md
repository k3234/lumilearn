# LumiLearn 与 OpenMAIC 对比分析（comparison-maic.md）

> 文档目的：说明 LumiLearn 与 OpenMAIC 的定位差异与工程改良方向。
> 表述原则：**基于已有 MAIC 范式完成场景化工程改进，不宣称全新范式，不宣称全面超越。**

---

## 一、OpenMAIC 简介

OpenMAIC 是一个基于 MAIC（Multi-Agent Interactive Classroom）范式的开源多智能体课堂项目，核心思路是由 AI 教师、AI 同学等多个 Agent 组成一个虚拟课堂，围绕同一学习目标开展讲授、提问、讨论与测验的交互式学习。其相关论文信息见 `docs/reference.md`。

### OpenMAIC 现存局限（本项目改良方向）

| 局限 | 说明 |
|---|---|
| **部署门槛高** | 通常依赖云端大模型 API，低配硬件上难以独立运行演示 |
| **缺少国内 K-12 学情长期记忆** | 会话间缺少可回流的学情标签与错题沉淀，授课难度难以动态调整 |
| **缺少低配硬件适配** | 未针对纯 CPU、低内存设备做专门优化 |
| **业务面向不聚焦** | 通用课堂场景，未针对国内高中数理化自学流程做业务适配 |

## 二、LumiLearn 的三项工程改良

基于 MAIC 范式，本项目面向国内高中数理化学科自学场景，完成三项**工程层面**改进：

1. **改良①（部署适配）**：Ollama 本地 / 云端 API 双模式适配。低配 CPU 设备可一键切换本地 Ollama 模型完成演示，云端 API 作为可选项。
2. **改良②（业务适配）**：面向国内高中数理化自学流程做业务适配，覆盖"教—学—评—导"完整闭环（费曼五步教学 → 学生作答 → 五维评分 → 学习报告）。
3. **改良③（学情闭环）**：学习数据回流。会话记录、测验结果、错题标签写入本地学情知识库，后续课程按掌握度动态调整授课难度。

## 三、定位差异总览

| 维度 | OpenMAIC | LumiLearn |
|---|---|---|
| **定位** | 沉浸式虚拟课堂（多人互动课堂） | 课后自学 + 学情管理 |
| **应用场景** | 课堂内多人 Agent 互动教学 | 个人自学、低配设备演示、课后复习 |
| **部署** | 依赖云端大模型 API | Ollama 本地 / 云端 API 双模式 |
| **硬件要求** | 较高 | 纯 CPU 可运行（4GB 内存 + 4 核可跑最小闭环） |
| **学情记忆** | 会话内 | 跨会话持久化学情标签 + 错题回流 |
| **数据存储** | 云端为主 | 本地 SQLite，隐私优先 |

## 四、功能对照表

| 功能点 | OpenMAIC | LumiLearn | 说明 |
|---|---|---|---|
| 多 Agent 协作课堂 | ✅ | ✅ | 教师讲解 + AI 同伴互动 + 随堂测验 |
| 交互式学习引导 | ✅ | ✅ | 费曼五步 + 交互式单步引导（学生回答驱动） |
| 客观题测验与作答记录 | ✅ | ✅ | 随堂测验生成、作答结果落库 |
| 学情长期记忆 | ⚠️ 有限 | ✅ | 错题、答题标签入知识库，动态调难度 |
| 本地 / 云端模型切换 | ⚠️ 不完整 | ✅ | Ollama 本地 + 云端 API 一键切换 |
| 纯 CPU 低配运行 | ❌ | ✅ | 8M 自研模型 + 1.5B 量化模型 CPU 推理 |
| 数据本地隐私 | ❌ 默认云端 | ✅ | SQLite 本地持久化 |
| 教师 / 家长可视化 | ⚠️ | ✅ | 教师端掌握度趋势、薄弱点排行 |

## 五、相同之处（诚实说明）

LumiLearn 与 OpenMAIC 同属**基于大模型的多 Agent 交互式教学**路线，共享 MAIC 范式内核：

- 都采用"教师 Agent 讲授 + 同伴 Agent 互动"的多角色课堂结构；
- 都以交互式问答促进主动学习，而非单向内容播放；
- 都包含测验环节与作答反馈。

本项目**未提出全新范式**，而是在上述共性的基础上，针对部署门槛、国内 K-12 自学流程与学情闭环做工程化改良。

## 六、局限声明（不回避）

- 本项目尚未完成与 OpenMAIC 的**大规模对照实验**，仅基于小范围案例（真实服务运行 + 30 题标准化对比评测）开展验证；
- 本地 8M 自研模型在教学准确性上明显弱于大模型，仅用于演示与教学编排；
- 自研模型与 1.5B 量化模型均存在**大模型幻觉风险**，系统已输出幻觉风险提示文案并在安全声明中披露；
- 测试样本有限，学科覆盖聚焦数理化，未覆盖全学科。

## 七、结论

LumiLearn 是对 OpenMAIC 所提出 MAIC 范式的**应用层改良原型**：保留多 Agent 交互式课堂的核心结构，在部署适配、国内 K-12 业务适配与学情闭环三处做工程改进，目标场景为"低配硬件上的课后自学"。后续迭代将把 Agent 调度内核抽离为通用运行时 LumiFlow，LumiLearn 作为上层教育应用 Demo。
