# LumiLearn 参赛技术方案（GOAI 无界应用赛道）

> **作品名称**：LumiLearn — 本地优先 AI 教育智能体
> **一句话定位**：在普通 CPU 上即可运行、覆盖"教—学—评—导"完整闭环的 AI 教育系统
> **核心理念**：算力平权 —— 不依赖 GPU 与云端，让老旧设备、资源不足的学校也能享受个性化 AI 教育
> **开发者**：一名高一学生（选科物化生）
> **日期**：2026-08-12

---

## 一、项目概述

LumiLearn 是一套**完全在 CPU 上训练与推理**的 AI 教育系统。系统以**费曼学习法**为教学内核，通过**多 Agent 协作编排 + RAG 知识库检索增强 + 苏格拉底式交互引导**，为学生提供从"发起学习 → 五步教学 → 主动回答 → 评分反馈 → 学习报告"的完整闭环。

系统自研了 8M 参数的微型 Transformer（从 tokenizer 到推理全部手写），并对 Qwen2.5-1.5B 做了 LoRA 微调，量化（Q8_0）后部署到 Ollama，**纯 CPU 推理仅需 2-5 秒/次**，16 线程 CPU 即可流畅服务多个端口。

## 二、目标任务

| 维度 | 说明 |
|---|---|
| **解决什么问题** | AI 教育依赖 GPU/云端，成本高、隐私风险大、学校落地难；传统课堂缺乏个性化与即时反馈 |
| **目标用户** | 学生（初/高/大学）、自学者、教师、资源不足的学校 |
| **核心任务** | ① 学生输入任意学科知识点 → ② 系统按费曼五步引导学习 → ③ 学生主动回答 → ④ 五维评分反馈 → ⑤ 生成个性化学习报告 |
| **工程目标** | 单机多端口一体化部署、数据库驱动、可审计（推理过程全记录）、可复现（一键部署） |

│   ▼                   ▼                   ▼                 │

│                      模型层（Ollama 网关）                   │
│  lumilearn-v2 (1.5B Q8_0) · qwen2.5:1.5b · 自研 8M 模型     │

### 各层职责

| 层 | 关键模块 | 职责 |
|---|---|---|
| **模型层** | `framework/models/` · `lumilearn_shared.py` | Ollama 网关、端口级模型路由、`num_predict` 防发散 |
| **编排层** | `goai_multi_agent.py` · `framework/engines/feynman_engine.py` | 三 Agent 串行编排、费曼五步/交互式单步引导、失败降级 |
| **应用层** | `goai_web.py` · `teacher_portal.py` · `student_portal.py` · `framework/api/` | 7 个端口的 Web 服务与 REST API |
| **数据层** | `framework/database.py` · `framework/services/` | SQLite、RAG 倒排索引、推理日志、数据导出审批流 |

## 四、技术路线

```
自研 8M Transformer（从零训练）
        │  CPU 训练，46 分钟/轮
        ▼
Qwen2.5-1.5B LoRA 微调（671 条真实教学数据）
        │  CPU 训练，70 分钟/轮，avg_loss 0.4057
        ▼
GGUF 量化（Q8_0，1.64GB）→ Ollama 部署
        │  纯 CPU 推理 26.4 tok/s
        ▼
多 Agent 编排 + RAG 检索 + 引导式交互 → 多端口应用
```

| 技术点 | 实现 |
|---|---|
| 自研微型模型 | 8M 参数 Transformer，BPE tokenizer、训练/评测脚本全部手写（CPU 可训练） |
| 教学微调 | Qwen2.5-1.5B-Instruct + LoRA，671 条真实教学内容（平均 333 字/条） |
| 量化部署 | GGUF Q8_0（1.64GB），Ollama 管理，模型名 `lumilearn-v2` |
| 编排 | 无 LangGraph 依赖，自研串行编排器 + `agent_trace` 状态追踪 |
| RAG | 关键词倒排索引 + 简化 BM25（180+ 学科词典 + 2-gram 分词），零外部依赖 |
| 前端 | 原生 HTML/CSS/JS 单文件应用 + 本地化前端库（KaTeX/Chart.js/reveal.js） |

## 五、任务闭环

```
用户输入（学科/章节/问题）
    │
    ▼
① 任务理解：TaskUnderstanding 识别主题/学科/难度，归一化输入
    │
    ▼
② 流程编排：拆解为费曼五步（现象引入→认知冲突→思维模型→自主推导→费曼测试）
    │
    ▼
③ 工具调用：RAG 知识库检索注入 + 模型生成（端口级模型路由）
    │
    ▼
④ 交互引导：引导式学习——老师提问 → 学生自主回答 → 根据回答调整下一步引导
    │
    ▼
⑤ 结果交付：五维评分（简洁/准确/比喻/完整/术语）+ 学习报告（掌握度/薄弱点/建议/复习计划）
    │
    ▼
⑥ 异常处理：模型超时防发散（num_predict）、单 Agent 失败降级、RAG 检索失败静默降级
    │
    ▼
⑦ 效果验证：推理过程全量写库（reasoning_logs）+ 报告落库（learning_reports），管理员/教师可审计
```

## 六、创新点

1. **自研轻量模型 + 教学微调**：8M 自研模型 + Qwen2.5-1.5B LoRA 微调 + Q8_0 量化，全程 CPU 可复现（从数据构建到部署完整开源）。
2. **费曼学习法编排**：五步教学法落成可编排流程，且支持**交互式单步引导**（学生回答驱动，AI 根据回答调整提问）——不是"生成内容播放"，而是真正的引导式学习。
3. **多 Agent 协作**：教学→评分→建议三 Agent 串行编排，独立模型配置、失败降级、耗时追踪、推理全程留痕。
4. **CPU 推理优先**：端口级模型路由 + `num_predict` 防发散，多 Agent 全流程从 284 秒优化到 56 秒。
5. **RAG 零依赖**：关键词倒排索引 + BM25 简化版，1166 条知识库真实数据检索命中 5/5。
6. **数据合规闭环**：账号权限分级、教师本班数据隔离、数据导出管理员审批、推理记录全审计。

## 十、安全声明

- **AI 辅助教育工具边界**：LumiLearn 是 AI 辅助教学工具，**不替代教师**。AI 生成的知识讲解、练习题与学习报告仅供参考，请由教师/家长/学习者**人工校验后使用**。
- **幻觉风险提示**：大语言模型可能生成看似合理但错误的"幻觉"内容，涉及考试、升学等关键决策时务必以权威教材和教师意见为准。
- **数据本地存储**：学习数据默认存储在本机 **SQLite 数据库**，**不上传云端**；如需调用云端模型，仅按需发送请求文本，请勿提交含个人敏感信息的资料。
- **密钥走环境变量**：所有密钥（API Key、SECRET_KEY、管理员密码等）一律通过环境变量（`.env`）注入，不写入代码或配置文件，且 `.env` 已被 `.gitignore` 忽略、不进入公开仓库。
