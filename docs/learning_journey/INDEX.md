## 模块 0：基础设施 ⭐⭐☆☆☆

> 项目启动前的必备基础：数据存储、磁盘管理、文档规范。

### Module 0.1 — 存储管理与磁盘空间优化

- **文件**: [Module_0.1_存储管理.md](Module_0.1_存储管理.md)
- **难度**: ⭐⭐☆☆☆
- **前置知识**: 无（Python 基础即可）
- **简介**: 学习使用 Python 标准库监控磁盘空间、查找大文件、安全清理策略、符号链接迁移。实现一个完整的存储清理工具，深入理解"先预览后执行"的安全编程理念。
- **核心技能**: `shutil`、`glob`、`os.symlink`、JSON 日志、安全边界设计
- **对应项目文件**: `storage_cleaner.py`

### Module 0.2 — 文档管理与学习笔记体系

- **文件**: [Module_0.2_文档管理.md](Module_0.2_文档管理.md)
- **难度**: ⭐⭐☆☆☆
- **前置知识**: Module 0.1（推荐）
- **简介**: 建立三级文档体系（README → 模块文档 → API 文档），采用统一 Markdown 模板，Docs as Code 理念纳入 Git 管理。理解"文档是软件工程的隐形基础设施"。
- **核心技能**: Markdown 模板、文档分层、Git 版本控制、auto_logger 自动化
- **对应项目文件**: `archive/debug_scripts/auto_logger.py`（历史归档）、`docs/learning_journey/template.md`

## 模块 4：后端技能

> 使用 Python + Flask 构建多模态 AI 后端服务。

### Module 4.1 — Whisper 语音识别入门

- **文件**: [Module_4.1_Whisper入门.md](Module_4.1_Whisper入门.md)
- **难度**: ⭐⭐⭐☆☆
- **前置知识**: Python 基础、Module 0（推荐）
- **简介**: 学习 Whisper 模型原理（Encoder-Decoder 架构），使用 `openai-whisper` 在本地 CPU 上运行语音识别，构建 Flask 音频上传 API。掌握懒加载全局单例模式避免重复加载大型模型。
- **核心技能**: Whisper 模型、Flask multipart 上传、音频格式处理、懒加载模式
- **对应任务**: Task 4（LumiTerminal 语音识别前端）

### Module 4.2 — PaddleOCR 文字识别入门

- **文件**: [Module_4.2_OCR入门.md](Module_4.2_OCR入门.md)
- **难度**: ⭐⭐⭐☆☆
- **前置知识**: Module 4.1（推荐，了解 Flask 端点模式）
- **简介**: 学习 OCR 两阶段架构（检测 + 识别），使用 PaddleOCR 在 CPU 上实现高精度中文文字识别，构建 Flask 图片上传 API。与 Whisper 模块共享相同的代码风格和文件处理模式。
- **核心技能**: PaddleOCR、DB 检测网络、CRNN 识别网络、图片上传 API
- **对应任务**: Task 5（PaddleOCR 后端集成）

### Module 4.3 — Prompt 工程：AI 讲解内容自我审查

- **文件**: [Module_4.3_Prompt工程.md](Module_4.3_Prompt工程.md)
- **难度**: ⭐⭐⭐⭐☆
- **前置知识**: Module 4.1, 4.2（推荐，了解 Ollama 调用模式）
- **简介**: 学习 Prompt 工程的核心设计原则，基于学习科学理论（布鲁姆分类法、脚手架理论、ZPD）设计 4 维度审查 Prompt 模板，使用 Ollama 本地模型进行结构化 JSON 评分。理解"用最小的工程成本撬动 LLM 的最大能力"。
- **核心技能**: Prompt 设计、结构化输出、评分锚点、Ollama 调用、JSON 解析
- **对应任务**: Task 7（讲解自我审查引擎）

### Module 4.4 — 网络爬虫入门：学习资源获取

- **文件**: [Module_4.4_网络爬虫入门.md](Module_4.4_网络爬虫入门.md)
- **难度**: ⭐⭐⭐☆☆
- **前置知识**: Module 4.1, 4.3（推荐）
- **简介**: 学习 HTTP 请求原理和 BeautifulSoup 网页解析，实现 DuckDuckGo + Bing 双搜索引擎聚合，设计三级降级策略（搜索引擎 → 备用引擎 → 预设资源），使用 Ollama 本地模型生成 RAG 摘要。理解"爬不到时仍可用"的健壮性设计。
- **核心技能**: `requests`、`BeautifulSoup`、CSS 选择器、降级策略、RAG 摘要
- **对应任务**: Task 9（网络资源获取后端）

## 模块 5：前端技能

> 使用 HTML/CSS/JavaScript 构建交互式前端界面。

### Module 5.1 — 前端录音 API 集成

- **文件**: [Module_5.1_前端录音API.md](Module_5.1_前端录音API.md)
- **难度**: ⭐⭐⭐☆☆
- **前置知识**: HTML/CSS/JS 基础、Module 4.1（了解后端 API）
- **简介**: 学习浏览器原生 MediaRecorder API 采集音频，WebM+Opus 编码，FormData 上传到后端。掌握 getUserMedia 权限管理、录音状态机（待机/录音中/识别中/失败）、安全上下文（HTTPS/localhost）前条件。
- **核心技能**: `getUserMedia`、`MediaRecorder`、`Blob`、`FormData`、音频状态管理
- **对应任务**: Task 4（LumiTerminal 语音识别前端）

### Module 5.2 — 文件上传 API 设计

- **文件**: [Module_5.2_文件上传API.md](Module_5.2_文件上传API.md)
- **难度**: ⭐⭐⭐☆☆
- **前置知识**: Module 5.1（推荐，共享上传模式）
- **简介**: 学习 FileReader API 读取本地图片、FormData 封装上传、Drag & Drop API 拖拽上传。与语音上传共享相同的通信模式，建立 OCR 前端状态管理（待机/加载中/成功/失败）。
- **核心技能**: `FileReader`、`readAsDataURL`、`Drag & Drop`、图片预览、`FormData`
- **对应任务**: Task 6（LumiTerminal OCR 前端）

### Module 5.3 — 动态 UI 更新

- **文件**: [Module_5.3_动态UI更新.md](Module_5.3_动态UI更新.md)
- **难度**: ⭐⭐⭐☆☆
- **前置知识**: Module 5.1, 5.2（推荐）
- **简介**: 学习 DOM 动态插入（`insertBefore`）、逆序遍历查找元素、评分可视化（根据分数动态切换 CSS 类名）、fetch POST JSON 标准通信模式。建立完整的前端状态管理（就绪/加载中/完成/失败）。
- **核心技能**: `insertBefore`、`querySelectorAll` 逆序遍历、CSS 类名动态切换、fetch JSON
- **对应任务**: Task 8（讲解自我审查前端）

### Module 5.4 — 组件化开发

- **文件**: [Module_5.4_组件化开发.md](Module_5.4_组件化开发.md)
- **难度**: ⭐⭐⭐☆☆
- **前置知识**: Module 5.1, 5.2, 5.3（推荐）
- **简介**: 学习可折叠面板（collapsible panel）的 CSS 实现与 JavaScript 控制，max-height 过渡动画，双入口数据获取（输入框/历史消息回溯），`classList.toggle()` 状态切换，快捷键注册统一模式。掌握组件化 UI 的设计模式：按钮 → 面板 → 数据展示的完整链路。
- **核心技能**: `max-height` 过渡动画、`classList.toggle`、`handleKey` 扩展、三组件协作
- **对应任务**: Task 10（LumiTerminal 资源获取前端）

## 学习建议

1. **按顺序学习**：每个后端模块（4.x）对应一个前端模块（5.x），建议配对学习（4.1 → 5.1 → 4.2 → 5.2 ...），学完就能看到完整效果。
2. **动手实践**：每个模块都包含完整的代码示例，建议边学边写，不要只看不练。
3. **理解原理**：每个模块都有"原理简介"章节，先理解为什么，再学习怎么做。
4. **参考投票记录**：项目历史中每个模块的多模型投票决策过程曾记录在 `data/task_history.json`（现已归档，可了解不同方案的优劣权衡）。
5. **使用模板**：新笔记请使用 [template.md](template.md) 作为起点。
