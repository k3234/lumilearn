# LumiLearn：CPU 上的 AI 教育系统

## 项目简介
LumiLearn 是一款面向 AI+教育场景的开源智能教学系统，核心理念是“算力平权”——让没有高端显卡的普通电脑也能流畅运行 AI 教学服务。

## 技术架构
- **模型层**：自规划使用大模型指导（如DeepSeek-V4-flash）训练1.5B Transformer 模型（Q8_0 量化），在 CPU 上实现教学对话与知识讲解
- **编排层**：LangGraph 驱动的多模型并行调用，12 模型投票机制保证回答质量
- **应用层**：课堂模式、对话终端、GOAI 学习智能体（任务理解→费曼五步法→学习报告）
- **部署层**：一键部署脚本，CPU 环境即可完整运行

## 核心创新
1. **自研轻量模型**：从零构建 1.5B 参数教学模型，无需 GPU 即可运行
2. **费曼学习法编排**：将教学方法论固化为可执行的 AI 流程
3. **多模型协作**：12 个模型并行调用，投票汇总输出最佳答案
4. **完整教学闭环**：从任务理解到学习报告交付，覆盖教学全流程
