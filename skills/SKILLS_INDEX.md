## 📝 使用说明

### 如何使用某个Skill

1. **阅读 SKILL.md** - 了解技能功能和使用方法
2. **查看 README.md** - 快速入门指南（如果有）
3. **使用 Python API** - 如果有 `.py` 文件，可直接在代码中调用
4. **注入系统提示词** - 将 SKILL.md 内容添加到 AI 系统提示词

### 如何查看某个Skill详情

```bash
# 查看文件列表
ls <project-root>\lumilearn\skills\<skill-name>

# 查看技能说明
cat <project-root>\lumilearn\skills\<skill-name>\SKILL.md
```

### 如何注册新Skill

1. 在 `<project-root>\lumilearn\skills\` 下创建目录
2. 编写 `SKILL.md` (YAML frontmatter + Markdown详情)
3. 编写 `config.json` (可选)
4. 编写 `<skill>.py` (可选，提供Python API)
5. 更新 SKILLS.md 注册表
